# Generator match on the named prime-field fragment

Planning model: `gpt-5.6-sol`, reasoning `xhigh`.

Prepared comparison table for the proposed bounded proof; no claim is
admitted here and canonical definitions retain ownership.

Fix an odd prime `p` and require the arithmetic datum to contain the named
field `F_p`. Write `Q_p=Q_(F_p)`, `e_p=e_(F_p)`,
`w_p(a,b)=w_(F_p)(a,b)`, and

    b_x=w_p(x,0)e_p:1->Q_p.

All exponents below are in `F_p`, using `1/2 in F_p`. Define these existing
arithmetic amplitude terms:

    w_tilde(a,b)=zeta_p^(ab/2) w_p(a,b),
    s_p=sum_(x in F_p) zeta_p^(x^2/2) b_x b_x^dagger,
    cup_p=sum_(x in F_p) b_x tensor b_x,
    cap_p=cup_p^dagger.

Every coefficient lies in `R_p=Q(zeta_p,sqrt(p))`; in particular
`p^(-1/2)` also lies in `R_p`. These formulas introduce proof/work-order
shorthand only, not new canonical generators.

Define the matched term fragment `G_p^arith` to have objects `Q_p^tensor n`,
`n>=0`, and arrows generated under identity, composition, tensor and dagger
by the entries in the table below and coefficient scalar maps from `R_p`.
It is not closed under arbitrary new addition beyond the displayed selected
amplitude terms. It sits inside the already `R_p`-linear source, whose
equality remains the existing source congruence.

## Three equalities that must remain distinct

| equality | definition | implication and failure of converse |
|---|---|---|
| arithmetic source equality | equality in `A_I` is the least `R_p`-linear typed dagger-monoidal congruence generated by D1323 | FRP-CAT sends it to equal Hilbert maps; FRP-CAT claims no faithfulness, so equal matrices need not be source-equal |
| realized-map equality | literal equality of complex linear maps under `H` (and literal CP-map equality under `R`) | equal nonzero maps are projectively equal; phases and distinct Kraus/source lists can have equal CP realizations without source equality |
| projective equality | nonzero maps agree up to an arbitrary `c in C^times`, with zero separate | does not imply actual equality or source equality, and records no norm or probability |

The raw assignment `a |-> [H(a)]` is a well-defined comparison on source
terms, but quotienting the source by its semantic kernel would merely define
an image presentation. It would not prove that the quotient is canonical,
geometric, full, or the desired scalar-retaining lift.

## Coefficient-domain audit

The selected terms use only coefficients already in `R_p`:

- Weyl and phase factors are powers of `zeta_p`;
- `1/2` means an exponent modulo odd p, not a new complex denominator;
- Fourier is an existing generator whose realization has entries in
  `p^(-1/2)Q(zeta_p) subset R_p`;
- normalized Bell preparation uses `p^(-1/2)`;
- unnormalized cups/caps and their loop use integers.

This does not put every complex scalar of `Stab_p^amp` into arithmetic
syntax. For example a transcendental nonzero complex scalar need not lie in
the named number field `R_p`. Closed arithmetic diagrams still have
realizations with entries in `R_p`; no claim promotes them to all of `C`.

## What is deliberately outside the matched fragment

The full arithmetic source also contains extension-field objects, Frobenius
`u_E`, transfers `j_i,v_i`, code objects/maps `t_i,c_i`, and multiplication
gates `m_(E,d)` for `d>=2`. The latter are registered higher-hierarchy gates,
not Clifford generators. None is identified with pure stabilizer theory.
Characteristic-two defect/lift data remain the separate DG-CHAR2 interface;
this odd-prime table assumes no result from that unadmitted gate.
